# Academy Days · Resort Activities · Marbella 2026

Static website, ready for GitHub and Netlify. No build or Excel connection required.

## Publish on Netlify
Upload the contents of this folder to the root of a GitHub repository. Connect it to Netlify; leave the build command empty and publish the root directory (`.`). Alternatively, drag this entire folder into Netlify Drop.

## Content and images
Edit `activities-data.js` to update the live content. `activities.json` is a matching reference copy; the page does not fetch it. All activities share the 17:00–19:00 window. No particular activity dates are implied.

Padel and tennis each have 2 courts. All eight activities have photographs. Football, basketball, table tennis and swimming use the supplied photos. The Fitness card uses the existing fitness photograph.

The cover uses The Art of Free Time campaign photograph. The header keeps the Magna Marbella resort logo and uses text for Academy Days; the Academy Days logo is removed. Links lead to the Academy Days Hub, programme and group finder. Google Fonts supplies Newsreader and Inter (an internet connection is required for these fonts).
